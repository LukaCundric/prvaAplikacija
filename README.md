## 📱 Moja prva mobilna aplikacija

To je moja prva mobilna aplikacija, izdelana v **Android Studiu**.

# 🚀 O aplikaciji

Aplikacija je preprost začetek spoznavanja razvoja mobilnih aplikacij za Android.

Trenutno vsebuje samo en gumb **"Hello World!"**, s katerim lahko preverim delovanje aplikacije na virtualnem telefonu.

# 🎯 Namen projekta

Namen projekta je spoznati osnove izdelave Android aplikacij, delo z Android Studiem ter poganjanje aplikacije na virtualni napravi.

To je moj prvi korak v svet razvoja mobilnih aplikacij. 🚀
